# FitNimbus

**Fitness Reimagined.**

Real-time camera analysis meets retro simplicity. No subscriptions. Just code & gains.

## Project Info

This project is a modern fitness application built with:
- **Vite**
- **TypeScript**
- **React**
- **shadcn-ui**
- **Tailwind CSS**

## Features

- **AI Coach**: Real-time form analysis using your camera.
- **Battle Arena**: Global leaderboard and gamification.
- **Diet Planner**: Manage your nutrition.
- **Community**: Open source hub.

## Getting Started

### Prerequisites

- Node.js & npm installed.

### Installation

1. Clone the repository:
   ```sh
   git clone <YOUR_GIT_URL>
   ```

2. Navigate to the project directory:
   ```sh
   cd fitnimbus
   ```

3. Install dependencies:
   ```sh
   npm install
   ```

4. Start the development server:
   ```sh
   npm run dev
   ```

   **Note for Windows PowerShell Users:**
   If you encounter a "running scripts is disabled" error, use this command instead:
   ```sh
   cmd /c "npm run dev"
   ```

## Deployment

You can deploy this project to any static hosting service like Vercel, Netlify, or GitHub Pages.

1. Build the project:
   ```sh
   npm run build
   ```

2. Deploy the `dist` folder.
